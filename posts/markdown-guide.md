## 什么是 Markdown？

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它允许你使用易于阅读、易于编写的纯文本格式编写文档，然后将其转换为有效的 HTML。

## 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

### 强调

```markdown
**粗体文本**
*斜体文本*
***粗斜体***
~~删除线~~
```

### 列表

无序列表：

```markdown
- 第一项
- 第二项
  - 子项 A
  - 子项 B
```

有序列表：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](image.jpg)
```

### 引用

```markdown
> 这是一段引用。
> 可以多行书写。
```

### 代码

行内代码使用反引号：`code`

代码块使用三个反引号：

```python
def hello():
    print("Hello, Markdown!")
```

### 表格

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

### 分割线

使用三个或更多的 `-`、`*` 或 `_`：

```markdown
---
```

## 进阶技巧

### 任务列表

```markdown
- [x] 已完成的任务
- [ ] 待完成的任务
- [ ] 另一个待办事项
```

### 脚注

```markdown
这里有一个脚注[^1]。

[^1]: 这是脚注的内容。
```

### 数学公式

支持 LaTeX 数学公式：

行内公式：`$E = mc^2$`

独立公式：

```math
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
```

## 写作建议

1. **保持简洁**：用最少的文字表达最清晰的意思
2. **善用标题**：让文章结构一目了然
3. **代码要规范**：标注语言类型，保持缩进
4. **多用列表**：比大段文字更易读
5. **适当留白**：段落之间留空行，提高可读性

## 总结

Markdown 是程序员必备的技能之一。掌握了它，你就能高效地编写文档、写博客、记笔记。而且它的语法非常简单，花半小时就能学会基本用法。

> 好的工具应该让你专注于内容，而不是格式。Markdown 正是这样的工具。
