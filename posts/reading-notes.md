## 关于这本书

最近读了一本关于学习方法的书，书中提到了很多科学的学习策略。我把其中最有价值的部分整理成了这篇笔记。

## 核心观点

### 1. 间隔重复 > 集中突击

研究表明，分散学习的效果远好于临时抱佛脚。

```
集中突击：  |||||||||| → 短期记忆，很快遗忘
间隔重复：  |  |  |  |  | → 长期记忆，持久稳固
```

**实践方法**：

- 第 1 天学完后，第 2 天复习一次
- 第 4 天再复习一次
- 第 7 天再复习一次
- 第 15 天最后一次复习

### 2. 主动回忆 > 被动重读

不要一遍遍地看书，而是合上书本，尝试回忆内容。

| 方法 | 效果 | 效率 |
|------|------|------|
| 被动重读 | ⭐⭐ | 低 |
| 划线标注 | ⭐⭐⭐ | 中 |
| 主动回忆 | ⭐⭐⭐⭐⭐ | 高 |
| 费曼技巧 | ⭐⭐⭐⭐⭐ | 最高 |

### 3. 费曼技巧

这是我认为最有效的学习方法：

1. **选择概念**：确定你要学习的概念
2. **教给别人**：用最简单的语言解释它（假设对方是小学生）
3. **发现盲区**：解释不清楚的地方就是你没理解的地方
4. **简化再简化**：用更简单的语言和类比重新表达

> 如果你不能用简单的语言解释它，你就没有真正理解它。 —— 费曼

### 4. 交错练习

不要只练习同一类型的题目，把不同类型的题目混合起来练习。

```javascript
// 不好：按类型集中练习
练习: [A, A, A, B, B, B, C, C, C]

// 好：交错混合练习
练习: [A, B, C, A, C, B, C, A, B]
```

虽然交错练习在过程中感觉更难，但长期效果更好。

### 5. 睡眠的重要性

睡眠不是浪费时间，而是大脑整理和巩固记忆的关键时期。

- 🧠 睡眠中大脑会重播白天学习的内容
- 🔗 睡眠帮助建立新的神经连接
- 🧹 睡眠清除大脑中的代谢废物

**建议**：学习后保证充足的睡眠，尤其是深度睡眠。

## 实践清单

把理论转化为行动：

- [ ] 制定间隔重复计划
- [ ] 每次学习后用费曼技巧自测
- [ ] 把被动阅读改为提问式阅读
- [ ] 安排交错练习
- [ ] 保证每天 7-8 小时睡眠
- [ ] 学习前做 5 分钟冥想，提高专注力

## 我的感悟

读完这本书，我最大的感悟是：**学习本身也是一项需要学习的技能**。

我们花十几年时间学习各种知识，却很少有人教我们"如何学习"。掌握了科学的学习方法，学习效率可以成倍提升。

```python
# 伪代码：高效学习的公式
def efficient_learning():
    while True:
        learn_new_concept()
        sleep_well()           # 巩固记忆
        recall_without_notes()  # 主动回忆
        teach_others()          # 费曼技巧
        review_at_intervals()   # 间隔重复
```
