## 开篇

你好，欢迎来到我的博客！这是我的第一篇文章，也是这个博客的起点。

搭建这个博客的过程比想象中要简单——没有使用任何框架，纯手写的 HTML、CSS 和 JavaScript。整个过程充满了乐趣，也让我重新审视了"简单"的力量。

## 为什么要手写博客？

市面上有无数优秀的博客框架：Hexo、Hugo、Jekyll、Gatsby……它们功能强大，生态丰富。但我选择了一条"笨"路——从零开始手写。

原因很简单：

1. **完全掌控**：每一行代码都是我写的，我知道它为什么在那里
2. **零依赖**：不需要 `npm install`，不需要构建步骤
3. **学习价值**：在这个过程中，我对 Web 开发有了更深的理解
4. **极简主义**：只保留真正需要的功能

## 技术栈

这个博客的技术栈非常简单：

- **HTML5** — 页面结构
- **CSS3** — 样式和主题
- **Vanilla JavaScript** — 交互逻辑
- **marked.js** — Markdown 渲染
- **highlight.js** — 代码高亮
- **GitHub Pages** — 免费托管
- **GitHub Actions** — 自动部署

没有 React，没有 Vue，没有 Webpack。就是这么朴素。

## 代码示例

写代码的博客怎么能没有代码块？这是一段 JavaScript：

```javascript
// 一个简单的问候函数
function greet(name) {
  const hour = new Date().getHours();
  if (hour < 6) return `${name}，夜深了，早点休息 🌙`;
  if (hour < 12) return `早上好，${name} ☀️`;
  if (hour < 18) return `下午好，${name} 🌤️`;
  return `晚上好，${name} 🌆`;
}

console.log(greet('朋友'));
```
